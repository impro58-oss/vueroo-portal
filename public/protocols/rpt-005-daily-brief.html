RPT-005 Daily Brief Protocol

Department: RPT (Reporting) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: DRAFT

Purpose

Compile and deliver the morning brief at 8:00 AM IST with priority actions, system health, and blockers.

Trigger

  • Daily at 7:00 AM IST (cron job compiles, delivers at 8:00 AM)

    • Prerequisites

  • All automated systems ran their overnight cycles
  • Memory files are current
  • Dashboard health check completed

    • Steps

    Step 1: Gather Data (7:00 AM)

    Check each system:
  • AgentVue/TrojanVue: Latest P&L, open positions, any alerts
  • NeuroVue: Latest competitive intelligence updates
  • LotteryVue: Latest predictions, scoring results
  • CryptoVue: Latest scan results
  • Dashboard health: All endpoints responding?
  • Cron jobs: Any failures overnight?

    • Step 2: Compile Priority Actions

    List the top 3-5 things Roo needs to decide or act on: 
    markdown

    🔴 Priority Actions
    
1. [URGENT] [What needs attention]
2. [IMPORTANT] [What needs a decision]
3. [FYI] [What happened overnight]
