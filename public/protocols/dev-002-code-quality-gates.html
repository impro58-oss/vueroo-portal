DEV-002 Code Quality Gates Protocol

Department: DEV (Development) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: ACTIVE

Purpose

Every piece of code that gets deployed passes through these gates. No exceptions. This prevents the recurring pattern of "it works on my machine" → broken in production.

Trigger

  • Before ANY code deployment
  • Before ANY git push that affects live systems
  • After ANY code change that could break existing functionality

    • Steps

    Gate 1: Syntax & Structure

    Python: python -c "import ast; ast.parse(open('file').read())" — no SyntaxError
    JavaScript: node --check file.js — no SyntaxError
    No hardcoded secrets (API keys, passwords, tokens)
    All imports resolve (no missing dependencies)
    File encoding is UTF-8

    Gate 2: Functional Test

    Dry run completes without error
    Small batch produces expected output
    Edge cases handled (empty input, missing data, timeout)
    Error handling covers main failure modes

    Gate 3: Live Verification

    Output file exists and has content (not 0 bytes)
    Live URL returns data (fetch and check)
    Dashboard loads and displays data
    Cron job runs without error (if scheduled)

    Gate 4: No Regression

    Existing features still work (spot-check)
    No new NaN/undefined/null in output data
    No new 404s or broken links
    All internal links use absolute paths (/protocols/page.html), never relative (page.html)
    Navigation tested in browser: click every link, check console for errors (Learning 015, 019)
    Before/after comparison where applicable

    Gate 5: Documentation

    Code has docstrings on all functions
    Parameters documented and match implementation
    AGENTS.md updated if agent changed
    HEARTBEAT.md updated if system status changed
    .learnings/ updated if bug was found and fixed

    Decision Rules

    | Gates Passed | Action | |--------------|--------| | All 5 | ✅ Deploy | | 4 of 5 | ⚠️ Deploy with note (document which gate failed and why it's acceptable) | | 3 or fewer | ❌ Do NOT deploy — fix first |

    Error Handling

    | Failure | Response | |---------|----------| | Syntax error | Fix immediately, re-test from Gate 1 | | Functional test fails | Debug, fix, re-test from Gate 2 | | Live verification fails | DO NOT DEPLOY. Investigate. Fix. Re-test. | | Regression detected | Rollback. Investigate. Fix. Full re-test. |
