RSC-001 Multi-Source Research Protocol

Department: RSC (Research) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: ACTIVE

Purpose

Query multiple AI systems (Perplexity, Claude, ChatGPT, Gemini, Google) on a research topic, then synthesize a unified answer with proper citations and source attribution.

Trigger

  • When Roo asks for research that benefits from multiple perspectives
  • When verifying a claim that could be wrong
  • When preparing a high-stakes deliverable that needs adversarial review
  • When a single-source answer has LOW confidence

    • Prerequisites

  • Clear research question defined
  • PACK Operation active (Roo has access to Perplexity Pro, Claude)
  • Web search available (Brave built-in)
  • Gemini API key available (if not exhausted)

    • Steps

    Step 1: Frame the Question

  • Write the research question in precise, unambiguous terms
  • Identify what type of answer is needed: factual, analytical, predictive, creative
  • Set confidence threshold: what level of certainty is required?

    • Step 2: Query Each Source

    Perplexity (via Roo — PACK Operation):

  • Frame question with citation request: "Search for [X]. Provide sources for all claims."
  • Request format: "Based on current research, [question]. Cite your sources."

    • Claude (via Roo — PACK Operation):

  • Frame for deep reasoning: "Analyze [X] from first principles. What are the strongest arguments for and against?"
  • Request format: "Think step by step about [question]. Show your reasoning."

    • ChatGPT (via Roo — PACK Operation):

  • Frame for breadth: "What are the different perspectives on [X]?"
  • Request format: "Give me a comprehensive overview of [X], including minority viewpoints."

    • Gemini (via API — if available):

  • Use scripts/lumina-research.py with Gemini endpoint
  • Frame for factual grounding: "What are the established facts about [X]?"

    • Brave Web Search (built-in):

  • Search for recent developments: "[topic] 2026 latest research"
  • Search for counterarguments: "[topic] criticism problems"
  • Search for verification: "[specific claim] evidence proof"

    • Step 3: Extract Claims and Citations

    For EACH source response: 1. List every factual claim made 2. List every citation/source provided 3. Mark each claim as: VERIFIED | UNVERIFIED | CONTRADICTED 4. Flag any claim that contradicts another source

    Step 4: Cross-Reference

  • Create a claim matrix: claim × source
  • Claims agreed by 2+ sources → HIGH confidence
  • Claims from 1 source only → MEDIUM confidence (mark as UNVERIFIED)
  • Claims contradicted by another source → LOW confidence (flag for Roo)

    • Step 5: Synthesize

    Write a unified synthesis with:
  • Established findings (HIGH confidence, 2+ sources agree)
  • Probable findings (MEDIUM confidence, 1 strong source)
  • Disputed findings (LOW confidence, sources disagree)
  • Gaps (no source addressed this)
  • Recommendations (what to verify, what to accept)

    • Step 6: Cite Properly

    Every claim in the final output must have:
  • Source system (Perplexity/Claude/ChatGPT/Gemini/Web)
  • Original source if cited by the AI (journal, author, year, URL)
  • Confidence level (HIGH/MEDIUM/LOW)

    • Step 7: Deliver to Roo

  • Present synthesis in the format above
  • Flag any disputed claims for Roo's decision
  • Note what could NOT be verified and why

    • Quality Gates

    At least 2 sources queried
    Every factual claim has a source attribution
    Contradictions between sources identified and flagged
    No fabrication — gaps are labeled as gaps
    Confidence level assigned to every claim

    Error Handling

    | Error | Response | |-------|----------| | API key exhausted (Gemini) | Skip Gemini, note in output, use other sources | | Roo unavailable for PACK | Use Brave web search + built-in knowledge only | | Sources completely disagree | Present both sides, flag for Roo, do NOT pick a side | | No sources have information | Report "NO INFORMATION FOUND" — do NOT infer |
