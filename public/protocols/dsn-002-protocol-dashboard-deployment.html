DSN-002 Protocol Dashboard Deployment Protocol

Department: DSN (Design) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: DRAFT

Purpose

Deploy content to vueroo.com dashboards. Every dashboard follows the same process: build locally → test → push to GitHub → verify live.

Trigger

  • When creating or updating any vueroo.com dashboard page
  • When deploying new data to an existing dashboard

    • Prerequisites

  • vueroo-portal repo: C:\Users\impro\.openclaw\workspace\vueroo-portal
  • GitHub remotes configured (origin = vueroo-portal, upstream = rooquest1)
  • Content/data prepared and validated

    • Steps

    Step 1: Build Page/Data

    1. Create HTML file in vueroo-portal/public/[section]/ 2. Use semantic HTML5, mobile-first responsive CSS 3. All data fetched via shared fetchJSON helper with NaN sanitization 4. Dark/light mode support

    Step 2: Test Locally

    bash
cd C:\Users\impro\.openclaw\workspace\vueroo-portal
python -m http.server 8080

    Open http://localhost:8080/[section]/
    Page loads without console errors
    All data displays (no NaN, no undefined)
    Responsive on mobile viewport
    Links work

    Step 3: Git Commit & Push

    bash
cd vueroo-portal
git add public/[section]/
git commit -m "[section]: [what changed]"
git push origin main

    Step 4: Verify Live

  • Wait 30-60 seconds for GitHub Pages to deploy
  • Fetch https://vueroo.com/[section]/
  • Verify data loads and page renders
  • If GitHub Pages fails, check Actions tab for build errors

    • Step 5: Data-Only Updates (No HTML Change)

    If only updating JSON data: 
    bash
cp data/[file].json vueroo-portal/public/[section]/[file].json
cd vueroo-portal
git add public/[section]/[file].json
git commit -m "[section]: data update [date]"
git push origin main

    Quality Gates

    Local test passed
    Git push succeeded
    Live URL verified (200 response, data loads)
    No console errors on live page
