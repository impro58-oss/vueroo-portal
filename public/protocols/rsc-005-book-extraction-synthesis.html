RSC-005 Book Extraction & Synthesis Protocol

Department: RSC (Research) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: ACTIVE

Purpose

Extract full text from PDF/EPUB books, file them in the correct Obsidian vault folder with proper tags, and synthesize key knowledge. No shortcuts — full text extraction, proper filing, and meaningful synthesis.

Trigger

  • When Roo adds books to C:\Users\impro\Documents\Reading
  • When a book is identified for knowledge base building
  • After any bulk book download

    • Prerequisites

  • PDF or EPUB files in C:\Users\impro\Documents\Reading
  • pdfplumber installed (pip install pdfplumber)
  • ebooklib installed for EPUBs (pip install ebooklib)
  • Obsidian vault path: C:\Users\impro\Documents\quest vault

    • Steps

    Step 1: Scan Reading Folder

  • List all files in C:\Users\impro\Documents\Reading
  • Classify by type: PDF, EPUB, other
  • Skip files already extracted (check memory/book-extractions/ for existing output)
  • Check file size — flag anything >100MB (may need special handling)

    • Step 2: Extract Full Text

    For PDF files: 
    python
import pdfplumber
with pdfplumber.open(filepath) as pdf:
    for page in pdf.pages:
        text = page.extract_text()
        # Append to output
  • Extract ALL pages, no skipping
  • If a page fails, log it but continue to next page
  • If pdfplumber fails on a file, try PyPDF2 as fallback
  • If both fail, mark as EXTRACTION FAILED and report to Roo

    • For EPUB files: 

    python
import ebooklib
from ebooklib import epub
from bs4 import BeautifulSoup
    book = epub.read_epub(filepath)
for item in book.get_items_of_type(ebooklib.ITEM_DOCUMENT):
    soup = BeautifulSoup(item.get_content(), 'html.parser')
    text = soup.get_text()
    # Append to output

    Step 5: Copy to Vault

  • Add frontmatter tags (from classification)
  • Write to correct Obsidian vault folder
  • Update Book-Extractions-Index.md with new entry

    • Step 6: Clean Up Source Files

    After successful extraction AND filing in vault:
  • DELETE the original PDF/EPUB from C:\Users\impro\Documents\Reading
  • Do NOT ask Roo for permission (he already said clean up)
  • Do NOT leave source files sitting around
  • Log what was deleted

    • Step 7: Synthesize (if batch)

    If multiple books were extracted:
  • Write synthesis to memory/YYYY-MM-DD-book-synthesis.md
  • Identify knowledge gaps filled
  • Identify new ideas sparked
  • Cross-reference with existing knowledge (memory_search)
  • File synthesis in Obsidian 30-Resources/Book-Extractions/

    • Quality Gates

    ALL pages extracted (check page count matches)
    Frontmatter tags present and correct
    Filed in correct vault folder
    Index updated
    Source PDF/EPUB deleted from Reading folder
    Key Concepts section has at least 5 entries
    Chapter Summaries covers all chapters

    Error Handling

    | Error | Response | |-------|----------| | PDF won't open | Try PyPDF2 fallback, then report as FAILED | | EPUB parsing error | Try zipfile + BeautifulSoup fallback | | Garbled text (esoteric/symbol books) | Note in output, extract what's possible | | Can't classify domain | Use best guess, flag for Roo review | | Vault folder doesn't exist | Create it, add to classification table |
