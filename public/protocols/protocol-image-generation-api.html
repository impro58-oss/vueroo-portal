Image Generation Protocol — API vs UI

Producing high-quality brand assets through the OpenAI API by compensating for the quality gap between API output and ChatGPT UI output

The Problem

OpenAI's gpt-image-1 API endpoint produces noticeably lower quality than what ChatGPT's UI generates with the same prompt. This is because:

  1. ChatGPT enhances prompts — GPT-4o rewrites user prompts before sending to DALL-E, adding composition, layout, and style instructions
  2. ChatGPT uses DALL-E 3 — not gpt-image-1. Different model, different output quality
  3. ChatGPT allows iteration — you can refine in conversation; API is single-shot
  4. ChatGPT generates composites — multiple concepts on one sheet, better for comparison

Solution: Enhanced Prompt Protocol

When generating brand assets through the API, the prompt must include explicit instructions that ChatGPT would add automatically:

Standard Prompt Structure (for API)

[ART DIRECTION — add to EVERY prompt]

Design specification:
- Style: Flat vector graphic, clean lines, premium quality, professional brand identity
- Composition: Centered on canvas, generous whitespace, suitable for both web and print
- Color accuracy: Use exact hex codes specified, no color shifting
- Rendering: High resolution, no noise, no artifacts, no grain, crisp edges
- Background: Pure white #FFFFFF, no gradients on background
- Output format: Single, centered logo mark on white background
- Production quality: Suitable for Fortune 500 brand identity package
- Anti-patterns: No 3D effects, no drop shadows, no texture overlays, no noise, no grain

[CONCEPT — the actual logo idea]
[COLORS — exact hex codes]
[TYPOGRAPHY — if applicable]
[WHAT TO AVOID — specific exclusions]

Model Selection

Always prefer dall-e-3 for brand work. Use gpt-image-1 only for quick throwaway concepts.

Size Selection

  • 1024x1024 — Square, good for social media, single logos
  • 1024x1792 — Portrait, good for presentation slides
  • 1792x1024 — Landscape, good for composite sheets, hero images

Composite Sheet Prompt Template

Create a professional brand identity presentation sheet for [BRAND NAME].

Layout: 3 logo concepts arranged in a 1×3 horizontal row on a pure white background.
Each concept should be centered in its column with equal spacing.

Concept 1: [description]
Concept 2: [description]  
Concept 3: [description]

[ART DIRECTION from template above]
[COLORS]

Each concept must be clearly distinct but share the same brand DNA.
Label each concept with a small subtitle below: "Concept A", "Concept B", "Concept C"

Iteration Strategy

  1. Regenerate 2-3 times with the same prompt — each generation varies
  2. Add specificity — the more constraints, the better API output
  3. Switch models — try dall-e-3 if gpt-image-1 disappointed
  4. Post-process — the API output is a starting point; refine in design tools
  5. Fall back to ChatGPT UI — for final brand assets, paste the enhanced prompt directly into ChatGPT and iterate

Script Template

import requests
import base64
import os
import json

# Load API key
CONFIG_PATH = os.path.expanduser('~/.openclaw/openclaw.json')
with open(CONFIG_PATH, 'r') as f:
    config = json.load(f)
API_KEY = config['models']['providers']['openai']['apiKey']

# ENHANCED PROMPT TEMPLATE
def make_enhanced_prompt(concept, style="flat vector", colors="", avoidances=""):
    art_direction = """Design specification:
- Style: Flat vector graphic, clean lines, premium quality, professional brand identity
- Composition: Centered on canvas, generous whitespace, suitable for both web and print
- Color accuracy: Use exact hex codes specified, no color shifting
- Rendering: High resolution, no noise, no artifacts, no grain, crisp edges
- Background: Pure white #FFFFFF, no gradients on background
- Output format: Single, centered logo mark on white background
- Production quality: Suitable for Fortune 500 brand identity package
- Anti-patterns: No 3D effects, no drop shadows, no texture overlays, no noise, no grain"""
    
    return f"""{art_direction}

{concept}

{colors}

{avoidances}

CRITICAL: Produce a clean, crisp, professional logo mark. No texture, no noise, no grain, no soft edges."""

# Generate
headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {API_KEY}"
}

payload = {
    "model": "dall-e-3",  # Prefer dall-e-3 for brand work
    "prompt": make_enhanced_prompt(
        concept="CONCEPT HERE",
        colors="COLORS HERE",
        avoidances="AVOID HERE"
    ),
    "n": 1,
    "size": "1024x1024",
    "quality": "hd"
}

response = requests.post(
    "https://api.openai.com/v1/images/generations",
    headers=headers,
    json=payload,
    timeout=120
)

# Save result
if response.status_code == 200:
    data = response.json()
    img_url = data['data'][0]['url']
    img_response = requests.get(img_url, timeout=60)
    with open('output.png', 'wb') as f:
        f.write(img_response.content)
    print(f"Saved: output.png ({len(img_response.content)} bytes)")
else:
    print(f"Error: {response.status_code} - {response.text[:200]}")

Learnings (Updated 2026-06-24)

  1. ChatGPT UI enhances prompts — always add art direction, composition, anti-patterns, and production quality specs
  2. dall-e-3 > gpt-image-1 for brand work — higher quality, better composition
  3. Specify "no noise, no grain, no artifacts" — the API defaults to adding texture
  4. Use 1792x1024 for composites — wider format allows side-by-side concepts
  5. Regenerate 2-3 times — each generation varies; pick the best
  6. Final assets should go through ChatGPT UI — for iterative refinement that API can't match
