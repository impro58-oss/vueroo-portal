DEV-004 Dashboard Deployment Protocol

Department: DEV (Development) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: DRAFT

Purpose

Deploy data to vueroo.com dashboards with proper testing and verification. Every dashboard follows: build → test → push → verify.

Trigger

  • When creating a new dashboard page
  • When updating data on an existing dashboard
  • When deploying a new visualization or feature

    • Prerequisites

  • vueroo-portal repo: C:\Users\impro\.openclaw\workspace\vueroo-portal
  • GitHub remotes configured
  • Data files prepared and validated (no NaN, no undefined)

    • Steps

    Step 1: Build Locally

    1. Create HTML in vueroo-portal/public/[section]/ 2. Use semantic HTML5, mobile-first responsive CSS 3. Fetch data via shared fetchJSON helper with NaN sanitization:

    javascript
async function fetchJSON(url) {
    try {
        const res = await fetch(url);
        const data = await res.json();
        return sanitizeNaN(data);
    } catch (e) {
        console.error(Failed to fetch ${url}:, e);
        return null;
    }
}
    function sanitizeNaN(obj) {
    if (obj === null || obj === undefined) return null;
    if (typeof obj === 'number') return isNaN(obj) ? 0 : obj;
    if (Array.isArray(obj)) return obj.map(sanitizeNaN);
    if (typeof obj === 'object') {
        const out = {};
        for (const [k, v] of Object.entries(obj)) {
            out[k] = sanitizeNaN(v);
        }
        return out;
    }
    return obj;
}

    Step 2: Test Locally

    bash
cd C:\Users\impro\.openclaw\workspace\vueroo-portal
python -m http.server 8080

    Open http://localhost:8080/[section]/
    Page loads without console errors
    All data displays (no NaN, no undefined)
    Responsive on mobile viewport
    Dark mode works (if applicable)

    Step 3: Push to GitHub

    bash
cd vueroo-portal
git add public/[section]/
git commit -m "[section]: [what changed]"
git push origin main

    For data-only updates: 

    bash
cp data/[file].json vueroo-portal/public/[section]/[file].json
cd vueroo-portal
git add public/[section]/[file].json
git commit -m "[section]: data update [date]"
git push origin main

    Step 4: Verify Live

  • Wait 30-60 seconds for GitHub Pages
  • Fetch https://vueroo.com/[section]/
  • Verify: 200 status, data loads, no console errors
  • If GitHub Pages fails, check Actions tab

    • Step 5: Add to Health Check

    If dashboard is persistent: 1. Add URL to scripts/dashboard-health-check.py 2. Verify health check passes 3. Add cron for periodic monitoring

    Quality Gates

    Local test passed (no console errors)
    Data sanitization in place (no NaN/undefined)
    Git push succeeded
    Live URL returns 200 and data loads
    Mobile responsive
    Health check configured (for persistent dashboards)

    Error Handling

    | Error | Response | |-------|----------| | Local server won't start | Check port not in use: netstat -ano | findstr :8080 | | Data has NaN | Add sanitization in fetchJSON helper, re-test | | GitHub Pages 404 | Check repo settings → Pages → source branch, wait 2 min | | Data stale on live | Force browser cache clear, check GitHub Actions for deploy status |
