OPS-009 — Voice Note Transcription Protocol

Department: OPS (Operations)

Version: 1.1

Created: 2026-07-08

Updated: 2026-07-20 — Added GPT-3.5-turbo extraction cost control

Owner: Lumina

Status: ACTIVE

Trigger: Audio file received via Telegram (voice memo, audio attachment, or forwarded audio)

Purpose

Standardise the transcription of voice notes and audio attachments received through Telegram into accurate text, using the most efficient and cost-effective method. This protocol exists because local Whisper on CPU failed repeatedly for long audio files, and the OpenAI Whisper API is the correct default path.

This protocol is the single source of truth for audio transcription. Do not attempt local Whisper for files longer than 5 minutes.

Prerequisites

  • OpenAI API key stored at: C:\Users\impro\Documents\RooQuest Data\API's\Chat GPT API.txt
  • ffmpeg installed at: C:\Users\impro\AppData\Local\Programs\Python\Python311\Scripts\ffmpeg.exe
  • ffprobe installed at: C:\Users\impro\AppData\Local\Programs\Python\Python311\Scripts\ffprobe.exe
  • Python openai package installed

Steps

Step 1: Locate the Audio File

Audio files from Telegram are stored at:

C:\Users\impro\.openclaw\media\inbound\<uuid>.mp3

⚠️ CRITICAL: Telegram voice memos arrive as M4A files with a .mp3 extension. The extension is WRONG. Always verify the actual format before processing.

Step 2: Check File Format and Duration

Run ffprobe to determine the real format and duration:

& "C:\Users\impro\AppData\Local\Programs\Python\Python311\Scripts\ffprobe.exe" -v error -show_entries format=format_name,duration -of default=noprint_wrappers=1:nokey=1 "<audio_path>"

Record:

  • Actual format (e.g., mov,mp4,m4a,3gp,3g2,mj2 = M4A)
  • Duration in seconds (convert to minutes for cost estimation)

Step 3: Select Transcription Method

Duration Method Reason
< 2 min Local Whisper (tiny/base model) Fast enough on CPU, no API cost
2–5 min Local Whisper (base model) Acceptable CPU time (~1-2 min)
> 5 min OpenAI Whisper API Local CPU too slow, API cost negligible
> 60 min OpenAI Whisper API (split if needed) API has 25MB file size limit — split with ffmpeg if larger

Default: If unsure, use OpenAI Whisper API. Cost is $0.006/minute — a 30-minute file costs $0.18.

⚠️ EXTRACTION LLM COST CONTROL: After transcription, do NOT use GPT-4 for VOC extraction/analysis. Use GPT-3.5-turbo for the extraction step. GPT-4 costs ~$30/M input tokens vs GPT-3.5-turbo at ~$0.50/M input tokens — a 60x difference. A typical 30-min transcript (~5K tokens) costs ~$0.15 to extract with GPT-3.5-turbo vs ~$2.25 with GPT-4. The extraction quality difference is negligible for structured VOC analysis.

Step 4: Convert Format if Needed

If ffprobe reports anything other than a proper MP3 (most common: M4A/MP4), convert with ffmpeg:

& "C:\Users\impro\AppData\Local\Programs\Python\Python311\Scripts\ffmpeg.exe" -i "<input_path>" -ar 16000 -ac 1 -c:a libmp3lame -q:a 2 "<output_path>.mp3" -y

Settings:

  • -ar 16000 — 16kHz sample rate (sufficient for speech, smaller file)
  • -ac 1 — mono (voice memos are already mono)
  • -c:a libmp3lame — MP3 codec
  • -q:a 2 — good quality, small size

Step 5: Transcribe via OpenAI Whisper API

from openai import OpenAI

# Read API key
with open(r"C:\Users\impro\Documents\RooQuest Data\API's\Chat GPT API.txt", 'r') as f:
    api_key = f.read().strip()

client = OpenAI(api_key=api_key)

with open("<converted_mp3_path>", 'rb') as f:
    transcript = client.audio.transcriptions.create(
        model='whisper-1',
        file=f,
        response_format='text'
    )

# Save transcript
with open("<output_transcript_path>", 'w', encoding='utf-8') as out:
    out.write(transcript)

Step 6: Verify Transcript

  • Check transcript length is non-zero
  • Read first 500 characters to confirm content matches expected audio
  • If transcript is empty or garbled, retry with response_format='verbose_json' for debugging

Step 7: Route Transcript to Destination

Based on context, route the transcript to the appropriate pipeline:

Context Destination Action
VOC call (physician interview) VOC-Intelligence folder Run RPT-009-EXT output mode selection → present Roo with format options (quick brief / executive brief / full extraction / cross-VOC synthesis / action items)
General voice memo from Roo Respond in chat Summarise or act on content
Meeting recording Session log + vault Save to memory/session-logs/ and vault
Other Ask Roo Confirm where to route

⚠️ After VOC transcription: Always present Roo with the output mode menu (see RPT-009-EXT). Default is Quick Brief (voice message) immediately, with option for Full Extraction if requested.

Step 8: Clean Up Temporary Files

After transcription is confirmed successful:

  • Keep the transcript .txt file
  • Keep the converted .mp3 only if needed for re-processing
  • The original inbound .mp3 (actually M4A) can be left in place (OpenClaw manages media retention)

File size limit: 25MB per API request. For larger files, split with ffmpeg:

ffmpeg -i "<input>" -f segment -segment_time 1800 -c copy "<output_%03d.mp3>"

What NOT to Do

  • Do NOT attempt local Whisper (turbo model) for files > 5 minutes. It takes 30+ minutes on CPU and will timeout.
  • Do NOT trust the .mp3 file extension from Telegram. Always verify format with ffprobe first.
  • Do NOT skip format conversion. OpenAI API rejects M4A files mislabelled as MP3 with a 400 error.
  • Do NOT use response_format='text' for debugging. Use 'verbose_json' if you need segment-level timestamps or confidence scores.
  • Do NOT transcribe without checking duration first. You need duration to select the method and estimate cost.

Troubleshooting

Error Cause Fix
BadRequestError: Invalid file format File is M4A/MP4, not MP3 Convert with ffmpeg (Step 4)
Local Whisper timeout/hang CPU too slow for long audio Use OpenAI API (Step 5)
Empty transcript Audio too quiet or wrong language Add language='en' parameter
File too large (>25MB) Audio exceeds API limit Split with ffmpeg segment command
ffmpeg not found in PATH Binary in Python Scripts folder Use full path to ffmpeg.exe
