Routing Decision Tree

  1. systemEvent (main session)? → Already T1 (glm-5.1). No change.
  2. Isolated agentTurn?
    • Need MYTHOS-ENGINE (>50K context, multi-file, autonomous)? → T2 (deepseek-v4-pro)
    • Deep reasoning needed? → T2 (deepseek-v4-pro)
    • Short summary/brief (<200 words)? → T3 (deepseek-v4-flash)
    • Pure script execution, minimal reasoning?
      • Time-sensitive → T5 (llama3)
      • Overnight/no rush → T6 (gpt-oss:20b)
    • Fallback/verification? → T4 (kimi-k2.5)

Mythos-Mode Architecture

Mythos-Mode gives Lumina 1M+ effective context, multi-day autonomous work, and self-validation without Fable 5's cost or availability restrictions.

  • COMPASS.md (5K) — Auto-generated session orientation. "Where am I, what happened, what's next."
  • Context Rollover — When context fills past 80%, compress and archive to checkpoint, reload fresh.
  • DeepSeek-V4-Pro as Mythos Engine — T2 for deep analysis (1M context, 384K output).
  • Multi-Day Agent Protocol — Cron-spawned subagents: read checkpoint → work → write checkpoint → exit.
  • Recursive Excellence — OPS-006 self-validation replaces Fable 5's built-in reflection.
