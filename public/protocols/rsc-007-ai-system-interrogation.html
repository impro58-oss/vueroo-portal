RSC-007 AI System Interrogation Protocol

Department: RSC (Research) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: ACTIVE

Purpose

Query external AI systems (Perplexity, Claude, ChatGPT, Gemini, Google AI) in a structured way that maximizes answer quality, captures citations, and enables proper synthesis. Each AI system has strengths — use them correctly.

Trigger

  • When Roo wants to "ask Perplexity" or "ask Claude" about something
  • When doing multi-source research (feeds into RSC-001)
  • When a question needs a different perspective than Lumina can provide
  • When adversarial review is needed (different model checking our work)

    • Prerequisites

  • PACK Operation active (Roo's subscriptions available)
  • Clear question framed
  • Knowledge of which AI system is best for which type of query

    • AI System Strengths & Best Use

    | System | Best For | Weakness | Prompt Style | |--------|----------|----------|--------------| | Perplexity | Real-time web-grounded research, citations, current events | Deep reasoning, complex analysis | "Search for [X]. Cite all sources." | | Claude | Deep reasoning, analysis, code review, synthesis, nuance | Real-time data, citations | "Think carefully about [X]. Show your reasoning step by step." | | ChatGPT | Breadth, creative ideation, diverse perspectives, quick answers | Factual accuracy, hallucination risk | "Give me all the different perspectives on [X]." | | Gemini | Factual grounding, multimodal, long context, speed | Depth, nuanced reasoning | "What are the established facts about [X]?" | | Google AI | Search integration, real-time data, broad coverage | Reasoning depth | "Find the latest information about [X]." |

    Steps

    Step 1: Select the Right System

    Match question type to system:
  • "What's the latest on X?" → Perplexity (web-grounded, citations)
  • "Analyze this deeply" → Claude (reasoning, nuance)
  • "Give me ideas/perspectives" → ChatGPT (breadth, creativity)
  • "What are the facts?" → Gemini (grounding, speed)
  • "Verify this claim" → Perplexity + Claude (citation + reasoning)

    • Step 2: Frame the Prompt

    Rules for all prompts: 1. Be specific, not vague ("What is the 5-year recurrence rate for basilar tip aneurysms treated with flow diverters?" not "Tell me about aneurysms") 2. Request citations explicitly ("Cite your sources for every claim") 3. Request confidence levels ("Rate your confidence in each claim as HIGH/MEDIUM/LOW") 4. Request limitations ("What are you uncertain about?") 5. Set the persona when helpful ("You are a MedTech analyst with 15 years of experience")

    Perplexity-specific:

  • Use "Focus" mode for academic research
  • Use "Pro" mode for complex multi-step research
  • Always request: "Include journal citations with year and DOI where possible"

    • Claude-specific:

  • Use "Think step by step" for reasoning tasks
  • Request: "Before answering, consider what you DON'T know about this topic"
  • Request: "What assumptions are you making?"

    • ChatGPT-specific:

  • Use "Browse with Bing" for real-time data
  • Request: "What are the strongest arguments AGAINST your position?"
  • Request: "What would a skeptical expert say about this?"

    • Gemini-specific:

  • Use "Deep Research" mode when available
  • Request: "Ground every claim in a specific source"
  • Request: "Distinguish between established facts and emerging findings"

    • Step 3: Capture the Response

    When Roo pastes back an AI response: 1. Mark the source immediately (which system, what date) 2. Extract claims as a numbered list 3. Extract citations as a separate list 4. Mark confidence based on source system + specificity of claim 5. Flag anything that contradicts our existing knowledge

    Step 4: Validate Key Claims

    For any claim that will be used in a deliverable: 1. Cross-reference with at least 1 other source (web search, another AI, existing knowledge) 2. If VERIFIED by 2+ sources → tag [VERIFIED] 3. If from 1 source only → tag [UNVERIFIED] until Roo can confirm 4. If contradicted → flag for Roo's decision

    Step 5: File the Exchange

    Save to memory/ai-interrogations/YYYY-MM-DD-[topic]-[system].md with:
  • Original question sent
  • System queried
  • Full response received
  • Extracted claims + citations
  • Validation status
  • Confidence levels

    • Quality Gates

    Correct AI system selected for the question type
    Prompt includes citation request
    Prompt includes confidence level request
    Response claims extracted and numbered
    Key claims cross-referenced with at least 1 other source
    Results filed in memory/ai-interrogations/

    Error Handling

    | Error | Response | |-------|----------| | AI gives no citations | Note "NO CITATIONS PROVIDED", treat all claims as UNVERIFIED | | AI contradicts itself | Note both positions, flag for Roo | | AI seems confident but wrong | Trust verification over confidence; cross-reference | | Roo can't access PACK right now | Use Brave web search + Gemini API as fallback |

    Output

    Structured interrogation record filed in memory/ai-interrogations/ with full source, claims, citations, and validation status.
