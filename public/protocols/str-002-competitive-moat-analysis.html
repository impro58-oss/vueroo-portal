STR-002 Competitive Moat Analysis Protocol

Department: STR (Strategy) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: ACTIVE

Purpose

Identify and build defensible competitive advantages (moats) for our projects. From Zero to One: competition is for losers, creative monopolies drive progress.

Trigger

  • After completing STR-001 (Zero to One Audit)
  • When evaluating a project's long-term viability
  • When a competitor appears to be copying our approach

    • Steps

    Step 1: Identify Current Moats

    For each project, assess which moats exist today:

    | Moat Type | Description | Our Projects | |-----------|-------------|-------------| | Proprietary Technology | 10x better than closest substitute | Which projects have this? | | Network Effects | Product gets better as more people use it | Which projects have this? | | Economies of Scale | Cost per unit drops with volume | Which projects have this? | | Brand | People pay more for the brand | Which projects have this? | | Switching Costs | Hard to move to a competitor | Which projects have this? | | Data Moat | Proprietary data that competitors can't easily replicate | Which projects have this? | | Regulatory | Licenses, certifications, approvals that create barriers | Which projects have this? | | First Mover | Being first in a category creates advantages | Which projects have this? |

    Step 2: Assess Moat Strength

    For each moat identified:
  • Durability: Will this moat last 10+ years? (1-5 scale)
  • Breadth: How much of the business does it protect? (1-5 scale)
  • Replicability: How hard is it for competitors to copy? (1-5 scale)

    • Step 3: Identify Moat Gaps

    For projects WITHOUT strong moats:
  • What would make them defensible?
  • What's the minimum viable moat (easiest to build, most impactful)?
  • Is this project worth continuing without a moat? (Only if it funds a 0→1 play)

    • Step 4: Moat Building Plan

    For each moat gap:
