← Back to Protocol Dashboard ﻿# RSC-006 Web Research & Fact Verification Protocol

Department: RSC (Research) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: ACTIVE

Purpose

Search the web, verify facts, and cite sources properly. Prevent hallucination by always grounding claims in verifiable sources.

Trigger

  • Any claim that needs verification
  • Any research that requires current information
  • When cross-referencing information from other AI systems

    • Prerequisites

  • Brave Web Search (built-in, unlimited)
  • Clear research question defined

    • Steps

    Step 1: Frame the Search

    Turn your question into a search query:
  • Too broad: "neurovascular devices"
  • Good: "neurovascular flow diverter market size 2025 FDA clearance"
  • Best: "Pipeline embolization device FDA PMA approval rate 2024"

    • Rules: 1. Be specific: include dates, names, specific terms 2. Use quotes for exact phrases: "flow diverter" FDA 2024 3. Use site: for authoritative sources: site:fda.gov flow diverter 4. Add year for current data: market size 2025

    Step 2: Search

    Use web_search with the refined query.

    For each search: 1. Start with the most specific query 2. If no results, broaden incrementally 3. If too many results, narrow with additional terms 4. Use freshness parameter for recent information: freshness: "month" for last 30 days

    Step 3: Evaluate Sources

    Source reliability hierarchy: 1. Government/regulatory (FDA, SEC, EMA, ClinicalTrials.gov) → Highest trust 2. Peer-reviewed journals (PubMed, NEJM, Lancet) → High trust 3. Industry analysts (Grand View, Markets and Markets) → Medium trust (often paywalled) 4. Mainstream media (Reuters, Bloomberg, NYT) → Medium trust 5. Company websites/press releases → Low trust (self-reported, verify independently) 6. Blogs, forums, social media → Very low trust (verify everything)

    Step 4: Verify Claims

    For each important claim found: 1. Primary source check: Can you find the original source? 2. Corroboration check: Is the claim supported by at least 1 other independent source? 3. Recency check: Is the information current enough for your purpose? 4. Conflict check: Does any source contradict this claim?

    Tag each claim:

    — Found in 2+ reliable sources, primary source exists
    — Found in 1 source only, or source is low-trust
    — Sources disagree (present both sides)
    — Information is more than 2 years old for rapidly changing fields

    Step 5: Fetch Deep Content

    For important results, use web_fetch to read the full page:
  • Extract key data points with exact quotes
  • Note the author, date, publication
  • Note any methodology limitations
  • Check for updates or corrections

    • Step 6: Cite Properly

    Every claim in the output must include: 
    
[Claim] — [Tag] — Source: [Author, "Title," Publication, Date, URL]

    Example: 

    
The neurovascular device market is valued at $3.2B — [ESTIMATE] — Source: Grand View Research, "Neurovascular Devices Market," 2024, grandviewresearch.com

    Quality Gates

    Search queries were specific and targeted
    Sources evaluated using reliability hierarchy
    Every important claim has a tag
    Every claim has a citation with URL
    Conflicting information identified and flagged
    No claims presented as fact without a source

    Error Handling

    | Error | Response | |-------|----------| | No search results | Broaden query, try different terms, try different language | | Paywalled content | Note "PAYWALLED" and use abstract/summary only | | Conflicting sources | Present both, note conflict, flag for Roo's judgment | | Source is AI-generated | Verify with another source, tag as [UNVERIFIED] |
