RSC-008: Global Deep Research Protocol

Large-scale, multi-phase research projects producing foundational evidence bases for strategic decision-making

Purpose

This protocol governs large-scale, multi-phase research projects that produce foundational evidence bases for long-range strategic decisions. It is designed for projects that:

  • Span multiple geographic regions
  • Require multiple depth levels simultaneously
  • Need a reusable, searchable evidence repository
  • Feed into future-state analysis (Phase 2)
  • Must be defensible, source-referenced, and commercially relevant

This is NOT for quick lookups, single-source answers, or brief summaries. Use RSC-001 for those.

Internal Quality Rubric

Every section of the research must score HIGH on all ten dimensions before the dossier is considered complete:

  1. Source Quality — Tier 1 sources preferred. Every claim traced to its source.
  2. Evidence Hierarchy — Systematic reviews > RCTs > Cohort studies > Case series > Expert opinion > Market reports.
  3. Data Validation — Cross-referenced across at least 2 sources. Conflicting evidence presented with both sides.
  4. Regional Completeness — Every required region covered at minimum Level 1-2. Gaps explicitly noted.
  5. Strategic Relevance — Every finding answers "What does this mean for device development?"
  6. Forecasting Rigor — Future signals labeled as WEAK SIGNAL, EARLY INDICATOR, or ESTABLISHED TREND.
  7. Clinical Accuracy — All clinical claims verified against guideline sources (AHA/ASA, ESO, WSO, JNIS).
  8. Engineering Applicability — Device landscape includes specific products, manufacturers, and technical specifications.
  9. Commercial Relevance — Market sizes tagged [VERIFIED] or [ESTIMATE]. Reimbursement codes included.
  10. Actionability — Every section ends with strategic implications. The dossier enables decision-making.

Minimum target: 50-100 high-quality sources for a full Phase 1 research project.

Research Execution Phases

Phase 1: Global Landscape Research

  1. Define scope — regions, depth levels, timeline, strategic lens
  2. Build search framework — key terms, MeSH terms, search strings per region per level
  3. Execute systematic search — query all tiers, collect and catalog sources
  4. Extract and tag — pull claims, assign confidence, tag region/level/category
  5. Cross-reference — validate claims across sources, flag conflicts
  6. Regional analysis — write each region section with all 7 levels (where data exists)
  7. Global synthesis — executive summary, device landscape, knowledge gaps
  8. Phase 2 preparation — define key questions for future-state analysis
  9. Quality review — score against rubric, refine until all sections score HIGH

Phase 2: Future State Analysis

Phase 2 is ONLY informed by Phase 1 findings. It does NOT begin until Phase 1 is complete and reviewed by the stakeholder.

Session Management

  • Create a project file — memory/research/[project-name]/ directory
  • Checkpoint after every session — write progress to memory/research/[project-name]/progress.md
  • Source database — maintain memory/research/[project-name]/sources.md as a growing evidence repository
  • Use context rollover — when context fills past 80%, create checkpoint via scripts/context-rollover.py
  • Regenerate COMPASS — after significant progress, run python scripts/compass-generator.py

Quality Gates

  • Every claim has a source attribution (SRC-XXX format)
  • Every source has a complete entry in the literature database
  • Conflicting evidence is presented with both sides
  • No fabricated data — use UNKNOWN or [0.1 MARKER: no data found]
  • Confidence levels assigned to every major claim
  • Evidence, inference, and speculation are clearly separated
  • Strategic implications stated for every section
  • Regional gaps explicitly noted (not assumed)
  • All 7 depth levels addressed (or gaps noted)
  • Source count meets minimum (50-100)

Error Handling

ErrorResponse
Tier 1 source contradicts Tier 3Present Tier 1 as primary, note Tier 3 contradiction
No data exists for a regionWrite "NO DATA FOUND" — do NOT estimate from adjacent regions
Paywall blocks full textUse abstract + existing summaries, note access limitation
Source provides conflicting numbersPresent both, note methodology differences, assign MEDIUM confidence
Clinical terminology uncertainUse WHO/ICD terminology, cross-reference guideline sources
Market data only from company reportsTag as [ESTIMATE: company-reported], note potential bias

Output Format

  • Section A: Global Executive Summary
  • Section B: Regional Landscape Analysis (separate sections per region)
  • Section C: Global Device Landscape
  • Section D: Literature Database (structured evidence repository, min 50-100 sources)
  • Section E: Knowledge Gaps
  • Section F: Phase 2 Preparation (key questions only — do NOT perform Phase 2)

Deliverable Standard

The final dossier must be: evidence-based, source-referenced, defensible, executive-ready, R&D relevant, commercially relevant, clinically accurate, and globally informed.
