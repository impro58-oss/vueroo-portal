DEV-007 Git Commit & Push Protocol

Department: DEV (Development) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: DRAFT

Purpose

Standard git workflow: meaningful commits, proper branch management, verified pushes. Never leak secrets. Never mix local-only and deployable code.

Trigger

  • After completing any code change
  • Before deploying to production
  • After any data update

    • Steps

    Step 1: Review Changes

    bash
git status          # What changed?
git diff            # What exactly changed?
  • Verify no secrets (API keys, passwords, tokens) in the diff
  • Verify no Obsidian vault files (local-only) in the diff
  • Verify changes make sense

    • Step 2: Stage Intentionally

    bash
git add [specific files]   # NOT git add . unless you reviewed everything
    Rules:
  • ✅ git add public/trading/dashboard.json — specific, intentional
  • ✅ git add scripts/trojanvue_paper_trader_v51.py — specific, intentional
  • ❌ git add . — only if you reviewed every changed file
  • ❌ Never commit Obsidian vault files to GitHub (local-only)

    • Step 3: Write a Meaningful Commit Message

    Format: [scope]: [what changed]

    Examples:

  • trading: V5.2 tuned parameters + BTC filter + trailing stop
  • medtech: update competitor intelligence data
  • protocols: add 16 new protocol files
  • fix: LotteryVue scoring path mismatch
  • docs: update HEARTBEAT.md with cron fix status

    • Bad commit messages:

  • ❌ updates
  • ❌ fix stuff
  • ❌ wip
  • ❌ asdf

    • Step 4: Push to Correct Remote

    | Repo | Purpose | Remote | Branch | |------|---------|--------|--------| | vueroo-portal | Live dashboards | origin main | main | | workspace data | Data + scripts | origin master | master |

    bash
git push origin main    # For vueroo-portal
git push origin master  # For workspace

    Step 5: Verify Push

  • Check GitHub Actions for build success (vueroo-portal)
  • Check live URL to confirm deployment
  • If push fails, diagnose before retrying

    • Quality Gates

    No secrets in diff
    No Obsidian vault files in diff
    Meaningful commit message
    Push succeeded
    Live URL verified (for dashboards)

    Error Handling

    | Error | Response | |-------|----------| | Push rejected (non-fast-forward) | Pull first, resolve conflicts, push again | | Secret detected in diff | Remove from file, use .gitignore, commit removal | | Obsidian files in diff | Unstage them, they're local-only |

    References
