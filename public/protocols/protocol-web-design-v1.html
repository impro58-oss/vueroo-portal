Web Design Protocol — pARXYS Framework v1.0

Standardized approach for building world-class websites, reusable for pARXYS and any future project

1. The Law of Proximity

"If you want to be really good at something, you've got to get yourself exposed to other people or things that are really good in that area."

Before starting ANY website build, spend 15-30 minutes browsing award-winning sites. Don't just look — analyze. Ask: Why those colors? Why that spacing? Why that font? Why that layout?

Mandatory inspiration sources (check at least 3 before designing):

  1. Godly (godly.website) — Best for scroll animations, interaction design, premium feel
  2. Awwwards (awwwards.com) — Best for overall site excellence, judged by professionals
  3. CSS Design Awards (cssdesignawards.com) — Best for UI/UX/Innovation scoring
  4. Site of Sites (siteofsites.co) — Best for curated, detailed presentations with builder info
  5. Landbook (land-book.com) — Best for component-level search (testimonials, CTAs, etc.)
  6. Unsection (unsection.com) — Best for individual section layout inspiration

Category-specific sources: Commerce Cream (e-commerce), Killer Portfolio (portfolios), Minimal Gallery (minimal), Fonts in Use (typography), Hoverstates (interaction), Brutalist Websites (experimental).

2. What to Look For (4 Pillars)

Pillar 1: Typography

  • What font for headers? What font for body?
  • Are they from the same family or contrasting?
  • Rule: Maximum 2 typefaces. One for display/headlines, one for body
  • Weight variation: Use 3-4 weights of the same font (Light, Regular, Medium, Bold) rather than mixing families

Pillar 2: Color Palette

  • Every site uses a 60/30/10 color split: 60% dominant (background), 30% secondary (sections/cards), 10% accent (CTAs/highlights)
  • One color for ALL buttons — instant recognition
  • Dark mode is dominant in award-winning sites — premium feel

Pillar 3: Layout Design

  • Use consistent spacing system: 8px base unit (8, 16, 24, 32, 48, 64, 80, 96, 120)
  • Generous whitespace = premium feel. Tight spacing = budget feel.
  • Section-by-section thinking: don't design the whole page at once

Pillar 4: Animation

  • Hover effects on buttons and links
  • Scroll-triggered animations (fade in, slide up)
  • Background animations (subtle gradients, particle effects)
  • Rule: Animation should enhance, never distract.

3. Award-Winning Site Patterns

Hero Section

  • Full-viewport height (100vh) or near-full
  • Centered content with generous padding
  • One bold headline + one subline + one CTA
  • Background: dark gradient, video, or abstract visual

Feature Cards

  • 2-3 column grid on desktop, single column on mobile
  • Cards with subtle border (1px rgba), not heavy boxes
  • Hover: translateY(-4px) + subtle shadow

How It Works

  • Numbered steps (1, 2, 3) in a circle/gradient badge
  • Step title + description + detail line
  • Vertical layout (not horizontal timeline)

Social Proof

  • Logo bar (brands that trust us)
  • Testimonial cards with photo + name + role
  • Stats counter (X users, Y countries, Z satisfaction %)

Waitlist/CTA

  • Dark background section (carbon/near-black)
  • Centered content with email input + button on same row
  • "Sold out" or "Limited" badge above headline

Footer

  • Minimal: copyright + one link
  • No heavy navigation footer for landing pages

4. Build Process (Step-by-Step)

  1. Inspiration Board (15 min) — Browse 3-5 sites, save 3-5 screenshots, note specific elements
  2. Brand Definition (5 min) — Primary color (60%), secondary (30%), accent (10%), display font, body font, background, feel
  3. Structure (5 min) — Hero, Features, How it works, Social proof, Principles, Waitlist, Footer
  4. Build (60 min) — Start with structure, then colors/fonts/spacing, then hover effects/animations, then responsive
  5. Quality Check (10 min) — Visual hierarchy, 60/30/10 rule, button consistency, spacing grid, premium feel

5. Technical Standards

Typography

  • Headlines: Display font, clamp(32px, 5vw, 56px), weight 300-600
  • Subheadlines: Display font, clamp(18px, 2.5vw, 22px), weight 400
  • Body: Body font, 15-17px, weight 400, line-height 1.6-1.7
  • Labels: Body font, 11-13px, weight 600, letter-spacing 1.5-3px, uppercase

Spacing

  • Base unit: 8px
  • Section padding: 80-120px vertical, 40-48px horizontal
  • Card padding: 32-40px

Responsive Breakpoints

  • Mobile: < 768px (single column, stacked)
  • Tablet: 768-1024px (2 columns)
  • Desktop: > 1024px (3 columns, full layout)

Animation

  • Hover transforms: translateY(-2px to -6px) + shadow
  • Scroll animations: Intersection Observer, fade-in-up
  • Transition timing: 0.3s ease for hovers, 0.6s ease for page transitions

7. Self-Check Before Declaring Done

  • Does every section have clear visual hierarchy?
  • Is the 60/30/10 color rule followed?
  • Are all buttons the same color and style?
  • Is spacing on the 8px grid?
  • Does it look premium? (Compare to 3 Awwwards winners)
  • Are hover effects consistent across all interactive elements?
  • Does it work on mobile? (Check at 375px, 768px, 1024px, 1440px)
  • Is the waitlist/CTA section visually distinct from the rest?
  • Would you submit this to Awwwards honestly?
  • Load time under 3 seconds on 4G?
