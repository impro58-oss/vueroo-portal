RSC-003 Competitive Intelligence Protocol

Department: RSC (Research) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: ACTIVE

Purpose

Research competitors systematically: identify targets, gather data from public sources, validate claims, track movements over time, create competitor profiles. Feed NeuroVue with verified intelligence.

Trigger

  • When Roo asks "what are our competitors doing?"
  • When updating NeuroVue competitive intelligence data
  • When preparing a market brief or investor document
  • When a competitor announces something newsworthy

    • Prerequisites

  • Target competitors identified (or identify them in Step 1)
  • RSC-001 and RSC-007 understood (multi-source research, AI interrogation)
  • NeuroVue data structure understood: medtech-intelligence/dashboard/data/

    • Steps

    Step 1: Define the Competitive Landscape

    markdown

    Competitive Landscape Scan
    
Market: [e.g., "neurovascular embolization devices"]
Geography: [e.g., "global" or "US + Europe"]
Date: YYYY-MM-DD
    Tier 1 Competitors (Direct)
    
[Companies that compete head-to-head in the same segment]
    Tier 2 Competitors (Adjacent)
    
[Companies in related segments that could expand]
    Tier 3 Competitors (Emerging)
    
[Startups, new entrants, companies with pipeline products]

    Use Perplexity (via PACK) for initial landscape scan: "List all companies competing in [market segment]. Include company name, headquarters, key products, estimated revenue, and recent news."

    Step 2: Deep Dive on Each Competitor

    For each Tier 1 competitor, gather:

    Public financial data:

  • Annual/quarterly revenue (from SEC filings, annual reports)
  • Revenue growth rate
  • Market share estimates
  • Tag: [VERIFIED] only if from official filing. [ESTIMATE] if derived. [UNVERIFIED] if from third party.

    • Product portfolio:

  • Approved products (with FDA/CE clearance dates)
  • Pipeline products (with clinical trial phase)
  • Pricing (if publicly available)
  • Tag each product status as [APPROVED], [INVESTIGATIONAL], or [MARKETED]

    • Clinical evidence:

  • Key publications (search PubMed per RSC-002)
  • Clinical trial registrations (ClinicalTrials.gov)
  • FDA clearance/approval letters (FDA database)
  • Tag: [VERIFIED] from official sources only

    • Strategic moves:

  • Recent M&A activity
  • Partnership announcements
  • Executive changes
  • Conference presentations
  • Tag: [VERIFIED] from press releases, [UNVERIFIED] from rumors

    • Step 3: Validate All Claims

    For every competitor claim: 1. Financial claims → Cross-reference with SEC EDGAR filings (US) or company annual reports 2. Clinical claims → Cross-reference with ClinicalTrials.gov and PubMed 3. Product claims → Cross-reference with FDA 510(k) or PMA database 4. Market share → Tag as [ESTIMATE] unless from a verified market research report with methodology

    Hard rules from RSC-002:

  • No verified data → use 0.1 as marker
  • NEVER estimate financial data
  • Every claim gets a tag: [VERIFIED], [ESTIMATE], [UNVERIFIED], or [0.1 MARKER]

    Step 5: Update NeuroVue Data

    If the competitor is in the NeuroVue coverage area: 1. Update medtech-intelligence/dashboard/data/competitor-intelligence.json 2. Add source attribution to each data point 3. Push to GitHub: cd workspace && git add && git commit && git push 4. Verify live dashboard reflects changes at http://localhost:8766

    Step 6: Track and Monitor

    Set up ongoing monitoring:
  • Add competitor names to NeuroVue scan keywords
  • Schedule quarterly deep dives via cron
  • Flag any material changes (M&A, new product launch, clinical trial results) for immediate update

    • Quality Gates

    Every competitor identified and tiered (1/2/3)
    Every financial claim tagged [VERIFIED/ESTIMATE/UNVERIFIED/0.1]
    Every product status confirmed via FDA/CE database
    No financial estimates without explicit ESTIMATE tag
    NeuroVue data updated (if applicable)
    Profile filed in Obsidian vault

    Error Handling

    | Error | Response | |-------|----------| | Competitor is private, no financial data | Mark all financials as [UNVERIFIED], note "Private company" | | FDA database returns no results | May be CE-mark only (Europe) or not yet cleared. Note status. | | Conflicting revenue figures | Use most recent official filing, note discrepancy | | Competitor website makes claims with no published evidence | Tag [UNVERIFIED: company website, no published data] |
