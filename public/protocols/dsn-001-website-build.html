← Back to Protocol Dashboard ﻿# DSN-001 Website Build Protocol

Department: DSN (Design) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: ACTIVE

Purpose

Build and deploy a website from concept to live URL. Every website follows the same process: design → build → test → deploy → verify.

Trigger

  • When building a new website or web dashboard
  • When significantly redesigning an existing site

    • Prerequisites

  • Purpose defined (what is this site for?)
  • Content/data source identified
  • Hosting platform decided (GitHub Pages, local server, etc.)

    • Steps

    Step 1: Requirements

    markdown
Website: [Name]
Purpose: [1-2 sentences]
Target Users: [Who will use this?]
Data Source: [Where does data come from? API endpoint, JSON file, etc.]
Hosting: [GitHub Pages / localhost / other]
Domain: [vueroo.com/[path] / localhost:[port] / other]

    Step 2: Design the Layout

    Before coding: 1. List all sections the page needs 2. Sketch the layout (text description is fine) 3. Define the data flow: which component shows which data 4. Define responsive breakpoints (mobile, tablet, desktop)

    Step 3: Build Structure

    Use this standard file structure: 
    
[project-dir]/
  index.html       — Main page
  style.css        — Styles (or inline
