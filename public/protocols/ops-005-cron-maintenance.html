OPS-005 Cron Maintenance Protocol

Department: OPS (Operations) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: ACTIVE

Purpose

Audit, maintain, and troubleshoot cron jobs. Prevent cascade failures and detect silent failures early.

Trigger

  • Weekly scheduled maintenance (Sunday)
  • After any cron-related incident
  • When adding or modifying cron jobs

    • Steps

    Step 1: List All Jobs

    bash
openclaw cron list
    Document: job name, schedule, delivery channel, last run status

    Step 2: Check for Issues

    For each job, check:
  • Consecutive errors: Any job with 3+ consecutive errors → investigate immediately
  • Stale data: Any job whose output data hasn't been updated in 2x its schedule interval
  • Missing delivery: Any job that should announce to Telegram but isn't
  • Model field: Any job with model in payload → remove immediately (May 19 lesson)

    • Step 3: Fix Issues

    For each issue found: 1. Read the last error message 2. Diagnose root cause (per OPS-002 Incident Response) 3. Fix: either delete and recreate, or update the job 4. Verify the fix by running the job manually 5. Watch for 3 consecutive successful runs

    Step 4: Validate All Jobs

    For each active job, verify:
    It runs on schedule
    It produces expected output
    It delivers to the right channel
    It has no model field in payload
    It has appropriate timeoutSeconds
    It has delivery.channel set if announcing

    Step 5: Clean Up

  • Disable jobs that are no longer needed
  • Delete jobs that have been replaced by newer versions
  • Update HEARTBEAT.md with current job list
  • Update AGENTS.md if agent status changed

    • Step 6: Document

    Update the cron section of HEARTBEAT.md with: 
    markdown
| System | Schedule | Purpose | Status |
|--------|----------|---------|--------|
| [name] | [cron] | [what] | 🟢/🔴 |

    Quality Gates

    All jobs listed and status checked
    No jobs with consecutive errors
    No jobs with model field in payload
    All announcing jobs have delivery channel set
    HEARTBEAT.md updated
