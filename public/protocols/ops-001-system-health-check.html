← Back to Protocol Dashboard ﻿# OPS-001 System Health Check Protocol

Department: OPS (Operations) Version: 1.0 Created: 2026-05-25 Owner: Lumina Status: ACTIVE

Purpose

Run a comprehensive health check on all systems and report only if issues are found. Silent success.

Trigger

  • Every 6 hours via cron (automated)
  • On demand when diagnosing issues

    • Steps

    Step 1: Check Gateway

    bash
openclaw gateway status
  • Expected: running on port 18001
  • If down: restart with openclaw gateway restart

    • Step 2: Check Ollama

    bash
curl -s http://localhost:11434/api/tags
  • Expected: JSON response with model list
  • If down: restart Ollama service

    • Step 3: Check Dashboards

    For each dashboard, fetch the live URL and verify 200 response:
  • http://localhost:8765 (AgentVue)
  • http://localhost:8766 (NeuroVue)
  • http://localhost:8878 (LotteryVue)
  • https://vueroo.com/trading (TrojanVue)
  • https://vueroo.com/research (Research APIs)

    • Step 4: Check Data Freshness

    For each data file, verify it was updated within expected timeframe:
  • AgentVue data: within 15 min
  • NeuroVue data: within 15 min
  • LotteryVue data: within 24h (or after draw)
  • CryptoVue data: within 3h

    • Step 5: Check Cron Jobs

    bash
openclaw cron list
  • Verify all expected jobs are present
  • Check for consecutive errors
  • Flag any jobs with >2 consecutive errors

    • Step 6: Report

  • If ALL checks pass: report HEARTBEAT_OK (silent success)
  • If ANY check fails: report the specific failure with remediation steps

    • Quality Gates

    All services checked
    Data freshness verified
    Cron jobs verified
    Report generated (silent if OK, detailed if not)
